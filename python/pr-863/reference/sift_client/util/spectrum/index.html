    sift_client.util.spectrum ¶

    SPF1 v1 spectrum frames for bytes channels, as read by Spectrum View.

    One value is one spectrum: a 32-byte little-endian header, then float32 magnitudes. The timestamp is the window start; bin i is centered at start_hz + i * step_hz.

    Offset Type Field
    0 4 bytes Magic SPF1
    4 u8 Version, 1
    5 u8 Magnitude unit, a MagnitudeUnit value
    6 u8 Encoding, 0 = float32
    7 u8 Reserved, 0
    8 u32 Bin count
    12 f64 Start frequency in Hz
    20 f64 Bin step in Hz
    28 f32 Window in seconds, 0 = none
    32 count x f32 Magnitudes

    Spectrum View skips frames whose grid or unit differs from the first frame.

    Example 
    from sift_client.sift_types import FlowConfig
from sift_client.util.spectrum import SpectrumEncoder, spectrum_channel

flow = FlowConfig(name="rf", channels=[spectrum_channel("spectrum")])
encoder = SpectrumEncoder(sample_rate_hz=10e6, center_hz=2.4e9, frame_interval_s=0.1)
# per capture, with a streaming client for flow:
await stream.send(flow.as_flow(timestamp=t, values={"spectrum": encoder.encode(iq)}))

    Already have magnitudes? Use encode_spectrum_frame(mags, start_hz=..., step_hz=..., unit="dBm").

    Encode one spectrum as an SPF1 v1 bytes value.

    PARAMETER DESCRIPTION
    magnitudes

    1-D, one per bin, in unit. Stored as float32.

    TYPE: ArrayLike

    start_hz

    Bin 0 center, Hz.

    TYPE: float

    step_hz

    Bin spacing, Hz. Greater than 0.

    TYPE: float

    unit

    MagnitudeUnit, its byte, or its label ("dBm").

    TYPE: MagnitudeUnitLike DEFAULT: DBM

    window_s

    Waterfall row height in seconds. 0 lets the view pick.

    TYPE: float DEFAULT: 0.0

    RETURNS DESCRIPTION
    bytes

    32 + 4 * len(magnitudes) bytes.
    RAISES DESCRIPTION
    ValueError

    On any value Spectrum View would reject.

    spectrum_frame_from_samples ¶

    spectrum_frame_from_samples(
    samples: ArrayLike,
    *,
    sample_rate_hz: float,
    center_hz: float = 0.0,
    window: str | ArrayLike | None = "hann",
    full_scale: float = 1.0,
    window_s: float | None = None,
) -> bytes

    FFT one capture into an SPF1 v1 frame in dBFS.

    Real samples: one-sided, center_hz to center_hz + fs/2. Complex (IQ): two-sided around center_hz. Step is fs / len(samples). Window gain is corrected, so a tone of amplitude full_scale reads 0 dBFS; empty bins read -300 dBFS.

    PARAMETER DESCRIPTION
    samples

    1-D capture, real or complex.

    TYPE: ArrayLike

    sample_rate_hz

    Sample rate, Hz.

    TYPE: float

    center_hz

    Tuned frequency, Hz.

    TYPE: float DEFAULT: 0.0

    window

    "hann", "rect", None, or weights of length len(samples).

    TYPE: str | ArrayLike | None DEFAULT: 'hann'

    full_scale

    Amplitude that reads 0 dBFS.

    TYPE: float DEFAULT: 1.0

    window_s

    Defaults to the capture length; 0 = unset. Pass the frame interval when captures are shorter than it, or the waterfall has gaps.

    TYPE: float | None DEFAULT: None

    RAISES DESCRIPTION
    ValueError

    On invalid samples or arguments.
