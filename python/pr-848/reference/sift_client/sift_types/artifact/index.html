    ArtifactLinkRelation ¶

    Bases: Enum

    How a link relates an artifact version to another entity.

    ATTACHED_TO links carry forward to each new version. SOURCE and DERIVED_FROM links describe the bytes, so they carry forward only while the bytes do.

    ATTRIBUTE DESCRIPTION
    ATTACHED_TO

    Where the artifact surfaces, such as a conversation or canvas.
    SOURCE

    What the artifact was produced from, such as a run or asset.
    DERIVED_FROM

    Another artifact this one was derived from.

    ATTACHED_TO class-attribute instance-attribute ¶

    ATTACHED_TO = ARTIFACT_LINK_RELATION_ATTACHED_TO

    Where the artifact surfaces, such as a conversation or canvas.

    SOURCE class-attribute instance-attribute ¶

    SOURCE = ARTIFACT_LINK_RELATION_SOURCE

    What the artifact was produced from, such as a run or asset.

    DERIVED_FROM class-attribute instance-attribute ¶

    DERIVED_FROM = ARTIFACT_LINK_RELATION_DERIVED_FROM

    Another artifact this one was derived from.
