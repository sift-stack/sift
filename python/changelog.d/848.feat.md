`client.data_import.import_from_path` and `Run.import_data` take `leave_run_open` (default false) and a list of paths. When you have more than one file for a run, pass them in one call. That upload is one import into one run. Pass a mapping of path to config to set a file's config yourself. Files you leave out of the mapping are detected. A finished import stops its run and fires run-stop automations unless you set `leave_run_open`, then call `run.stop()` after the last import.
