# Installation

`sift-cli` ships prebuilt binaries for macOS, Linux, and Windows. You can also
build it from source.

## Prebuilt installers (recommended)

Releases are published with installer scripts generated by
[cargo-dist](https://github.com/axodotdev/cargo-dist). Run the installer for
your platform:

**macOS and Linux:**

```sh
curl -fsSL https://api.siftstack.com/install/sift-cli | sh
```

**Windows (PowerShell):**

```powershell
irm https://api.siftstack.com/install/sift-cli.ps1 | iex
```

The installer places the `sift-cli` binary on your `PATH`.

To install a specific version, append the version number without a `v` prefix:

```sh
curl -fsSL https://api.siftstack.com/install/sift-cli/0.5.0 | sh
```

```powershell
irm https://api.siftstack.com/install/sift-cli.ps1/0.5.0 | iex
```

## Build from source

You need a recent stable Rust toolchain. The build also generates this
documentation with [mdBook](https://rust-lang.github.io/mdBook/), so `mdbook`
must be on your `PATH`:

```sh
cargo install mdbook --locked
```

Then build and install the CLI:

```sh
git clone https://github.com/sift-stack/sift.git
cd sift/rust
cargo install --path crates/sift_cli
```

## Verify the install

```sh
sift-cli --version
```

If that prints a version, continue to [Configuration](./configuration.md) to
connect the CLI to your Sift environment.

## Shell completions

After installing, set up tab completion for your shell. See
